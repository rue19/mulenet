## Bugs found by this evidence work (all fixed, with tests)

1. **Receipts recorded tx identifiers, not hashes**, so the verifier resolved none of them. Receipts now record both, and the verifier checks a JSON copy.
2. **The Docker build without `--target` produced the console** and tagged it `mulenet/services`. The stage is now named, and every build passes `--target`.
3. **The Playwright external mode waited only for the console**, and failed while bank nodes were still syncing. It now waits for every service.
4. **Per-deployment data survived redeploys** inside the Docker volume, so new flags collided with stale `flag_index` rows. Data is now namespaced by contract address, and the bootstrap no longer deletes anything.
5. **A bank node with a fresh database gave up on quota slots** that were already spent on-chain. The next free slot is now read from on-chain nullifiers; the regression test fails on the old code.
6. **CI failed on a clean checkout:** the property `regressions/` directory was untracked. It is now tracked, and its absence is tolerated.
